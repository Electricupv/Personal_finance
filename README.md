# Личные финансы (CLI)

Консольное приложение для учёта доходов и расходов: несколько пользователей с авторизацией, категории, бюджеты
по категориям, подсчёт по категориям, оповещения о превышении бюджета и перерасходе, сохранение кошелька в файл.

## Запуск

- JDK 17 или новее, Maven 3.9+. Jackson подтягивается Maven автоматически.
- Сборка: `mvn clean package`
- Запуск: `java -jar target/Personal_finance-1.0-SNAPSHOT.jar`
- Тесты: `mvn test`

Данные хранятся в папке `data/`. Кошелёк загружается при `login` и сохраняется при `exit`.
Перед доходом, расходом и бюджетом категорию нужно создать командой `category`.

## Команды
Поля заполняются без кавычек.
Названия из нескольких слов указываются в кавычках "".

| Команда | Описание |
|---|---|
| `register <логин> <пароль>` | Регистрация |
| `login <логин> <пароль>` | Вход и загрузка кошелька |
| `income <категория> <сумма>` | Добавить доход |
| `expense <категория> <сумма>` | Добавить расход |
| `category <название>` | Создать категорию |
| `budget <категория> <сумма>` | Установить бюджет на категорию |
| `report [файл]` | Отчёт в терминал или в файл |
| `stats <категория1> [категория2 ...]` | Доходы и расходы по выбранным категориям |
| `exit` | Сохранение и выход |

## Структура

- `model` — данные: пользователь, кошелёк, операция.
- `service` — `AuthService` (пользователи, вход и выход), `FinanceService` (операции, бюджеты, подсчёты,
  оповещения), `FileStorage` (сохранение в JSON), `Validator` (проверки ввода).
- `cli` — чтение команд и вывод отчёта.
